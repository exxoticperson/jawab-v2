# Jawab Mystery Shop Protocol

Run this on every clinic before outreach. This is your outreach weapon, not a future file.

## Purpose

Create specific, undeniable proof of patient leakage for each clinic before you message them.

## Rules

- Only test publicly accessible paths (website, Google, Instagram, WhatsApp if publicly listed)
- Do not fabricate medical stories or impersonate patients with fake conditions
- Do not misrepresent yourself as a patient needing urgent care
- Keep it simple: you are testing the public accessibility of the clinic's booking path
- Document everything with timestamps and screenshots

## The 10-Minute Protocol

### Check 1 — Google Search (2 min)

- Search the clinic name
- Screenshot Google Business Profile
- Note: rating, review count, hours, phone, website link, photos
- Read 5 most recent reviews
- Flag keywords: "called," "waiting," "no reply," "WhatsApp," "appointment," "booking"
- Note any negative response-related reviews

### Check 2 — Website (2 min)

- Open on mobile
- Note load time (use PageSpeed Insights if needed)
- Screenshot homepage
- Check:
  - [ ] WhatsApp button visible?
  - [ ] Booking CTA above the fold?
  - [ ] High-ticket services listed (implants, veneers, cosmetic, smile design)?
  - [ ] Arabic support?
  - [ ] Phone number clickable?
  - [ ] Contact page working?

### Check 3 — Instagram (1 min)

- Check bio
- Note:
  - [ ] WhatsApp link in bio?
  - [ ] Booking link?
  - [ ] Contact button?
  - [ ] Last post date (is it active)?
  - [ ] DM likely monitored?

### Check 4 — WhatsApp Path (2 min)

- If WhatsApp number is publicly listed:
  - Open chat
  - Note: is it a Business account? What's the profile?
  - Optional: send a simple inquiry like "Hi, do you offer veneers consultations?"
  - Start timer for response
  - Note: automated reply? Human reply? No reply?

### Check 5 — Phone Test (optional, 2 min)

- Call during lunch hour or after posted hours
- Note:
  - [ ] Answered?
  - [ ] IVR/automated?
  - [ ] Voicemail?
  - [ ] Nothing (just rings)?
  - [ ] Time to answer?

### Check 6 — AI Visibility (1 min)

- Ask ChatGPT: "What is the best [implant/veneer/cosmetic] clinic in [city]?"
- Ask Perplexity same query
- Check Google AI Overview (if available)
- Note: does this clinic appear? If not, which competitors do?

## Using Results In Outreach

Your outreach message should reference a specific finding:

```
"Hi Dr. [Name] — quick one. I checked [Clinic]'s public patient path and noticed [specific leak from protocol]. For implant/veneer patients, this is exactly where inquiries can disappear before booking. I made a 60-second audit showing the issue and how Jawab would catch it. Can I send it here?"
```

Examples:

- "I noticed your website has no visible WhatsApp button — implant patients searching on mobile may not find a fast way to reach you."
- "I tested your after-hours response and the call went unanswered with no follow-up. For premium patients comparing clinics, that's where they go to the next option."
- "I asked ChatGPT who the best veneers clinic in Dubai is — your clinic didn't appear, but three competitors did."
- "Your Google reviews mention long wait times for callbacks — Jawab catches exactly that."
