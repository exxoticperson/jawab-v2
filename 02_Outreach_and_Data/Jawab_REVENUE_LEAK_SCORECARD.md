# Jawab Revenue Leak Scorecard

Use this scorecard before every outreach. Only contact clinics scoring 60+.

## Scoring Template

| Category | Weight | Score (0–max) | Notes |
|----------|--------|---------------|-------|
| Response Speed / Accessibility | /15 | | Call during lunch or after-hours. Did anyone pick up? How fast? |
| WhatsApp Path Clarity | /15 | | Is WhatsApp visible on website, Google, Instagram bio? Is it a business number or personal mobile? |
| Missed-Call Recovery | /15 | | After a missed call, did anything happen? SMS? WhatsApp? Nothing? |
| Booking CTA | /10 | | Is there a clear booking button/link on website and social? Or just "call us"? |
| Review Trust / Friction | /10 | | Google rating, review count, review recency. Any complaints about booking, waiting, or response time? |
| High-Ticket Service Clarity | /10 | | Are implants, veneers, cosmetic, smile design clearly listed and easy to find? Or buried? |
| Arabic / English Readiness | /10 | | Does website/social support both languages? Is Arabic copy natural or machine-translated? |
| AI / Search Visibility | /10 | | Search "best [treatment] clinic in [city]" — does this clinic appear? Ask ChatGPT/Perplexity same query. |
| Post-Consult Follow-up | /5 | | Any evidence of follow-up system? Review requests? Reactivation? Or nothing after visit? |
| **TOTAL** | **/100** | | |

## Fit Grading

- `0–30`: Weak fit — skip or deprioritize
- `31–60`: Some friction — needs more proof before outreach
- `61–80`: Strong opportunity — contact this week
- `81–100`: Urgent recovery candidate — contact today

## How To Run A Quick Score

### Step 1 — Google Search (2 min)

- Search clinic name
- Check Google Business Profile: rating, review count, photos, services listed
- Check if website loads, mobile speed, booking CTA
- Read 5 most recent reviews for words like: "called," "waiting," "no reply," "WhatsApp," "booking," "appointment"

### Step 2 — Website Check (2 min)

- Does it load on mobile in under 3 seconds?
- Is there a WhatsApp button?
- Is there a booking CTA above the fold?
- Are high-ticket services (implants, veneers, cosmetic) clearly listed?
- Is there Arabic support?

### Step 3 — Instagram / Social Check (1 min)

- Does bio have a WhatsApp link or booking link?
- Is there a contact button?
- Are DMs likely monitored?

### Step 4 — AI Visibility Check (2 min)

- Ask ChatGPT: "What is the best [implant/veneer/cosmetic] clinic in [city]?"
- Ask Perplexity same query
- Ask Google (check AI Overview if available)
- Does this clinic appear in any answer?

### Step 5 — Response Test (optional, 5 min)

- Call the main number during lunch or after-hours
- Send a WhatsApp message asking about a service
- Note: response time, quality, language

## Pain Proof Sentence

After scoring, write one sentence:

> "[Clinic] scores [X]/100. Main leak: [specific issue]. Jawab angle: [Recover/Visible/both]."

This sentence becomes the outreach opener.
