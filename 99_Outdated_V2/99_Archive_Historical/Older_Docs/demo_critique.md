# Skill: Demo Critique

## Goal

Sharpen the Jawab demo without turning it into a rebuild project.

## Required Inputs

- demo file or demo recording
- current Jawab offer
- audience for the demo

## Required Outputs

- what already works
- top 3 to 5 polish changes
- one optional high-impact feature only if clearly worth it

## Rules

- preserve the strongest existing scenes
- improve clarity before adding spectacle
- keep the demo aligned with dental patient recovery
