# Skill: Execution Verification

## Goal

Turn vague work into small verifiable tasks, then verify the actual artifact instead of trusting the summary.

## Use When

- creating or updating dashboard tasks
- finishing a file edit
- preparing an outreach batch
- checking whether "we have enough"
- deciding whether to automate

## Work Unit Rule

A task is too big if it cannot be checked in one sitting.

Rewrite it into:

- action
- artifact
- acceptance criteria
- next owner

## Verification Rules

- summaries are not proof
- file existence is not enough
- check the actual file, row, link, message, or screenshot
- mark unknowns as unknowns instead of smoothing them over

## Output

- task
- artifact checked
- pass/fail/uncertain
- next action
