## HOW TO USE THESE 9 SLIDES

**As an Instagram carousel:**
- Generate all 9 → arrange in order → add minimal text overlay in Canva (headline only, Inter Bold, white on dark)
- Post as a 9-image carousel

**As a WhatsApp pitch sequence:**
- Send slides 1, 6, 8 as standalone images with your DM
- Send the full set after interest

**As a video:**
- Import all 9 into CapCut or InShot
- 3 seconds per slide, slow Ken Burns zoom
- Add a subtle ambient track (dark, cinematic)
- Export as 15-second reel or 30-second story

**As a pitch deck:**
- Use each image as a full-bleed background slide in Canva
- Overlay the text from `Jawab_VISUAL_PITCH_KIT.md` on top
- Export as PDF

## TIPS FOR BEST RESULTS

**Midjourney:**
- Add `--ar 1:1` for square
- Add `--s 250` for high stylization
- Add `--v 6.1` or latest version
- Add `--no text, letters, words, watermark` to avoid unwanted text

**Ideogram:**
- Best for any prompt that needs text rendered on the image
- Use "Magic Prompt" off for more control

**Flux (via Replicate or fal.ai):**
- Best photorealism
- Great for the product/still-life prompts

**Leonardo AI:**
- Good for the 3D/holographic dashboard prompt
- Use "DreamShaper" or "Absolute Reality" models

**For the logo:**
- Generate 20+ variations
- Pick the cleanest one
- Recreate it in Figma or Canva as a vector for actual use
- The AI-generated version is a reference, not the final logo
