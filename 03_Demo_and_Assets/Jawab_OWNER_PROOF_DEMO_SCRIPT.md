# Jawab Owner Proof Demo Script

This is the practical 90-second demo. Not the cinematic one. This is for closing.

## Purpose

Show a clinic owner exactly what happens when a patient leaks — and how Jawab catches them.

## Duration

90 seconds maximum.

## Script

### Scene 1 — The Leak (0:00–0:20)

```
[Screen shows a patient finding a clinic on Google Maps]
[Patient taps "Call"]
[Phone rings. No answer.]
[Screen text: "Tuesday 1:15 PM. Lunch hour."]
[Patient hangs up.]
[Screen text: "Patient was looking for veneers. AED 15,000 case."]
```

### Scene 2 — Jawab Catches It (0:20–0:40)

```
[Jawab detects the missed call]
[Patient receives WhatsApp message in Arabic:]
"أهلاً، لاحظنا إنك اتصلت بعيادة [اسم العيادة]. كيف نقدر نساعدك؟"

[Patient replies: "أبي استشارة فينير"]
[Jawab qualifies: service interest, urgency, preferred callback time]
```

### Scene 3 — Staff Handoff (0:40–0:55)

```
[Staff contact receives WhatsApp summary:]

New patient inquiry:
- Name: [Patient Name]
- Language: Arabic
- Service: Veneers consultation
- Urgency: This week
- Preferred callback: After 5 PM
- Source: Missed call
- Next action: Call back and offer consult slot

[Screen text: "Staff calls patient back. Consult booked."]
```

### Scene 4 — Owner Sees The Report (0:55–1:15)

```
[Weekly Jawab Intelligence Report on screen:]

This week:
- 12 patient inquiries detected
- 8 recovered conversations
- 5 qualified leads routed to staff
- 3 consult bookings
- Estimated at-risk patient value: AED 45,000
- Recovery rate: 67%
- Main bottleneck: WhatsApp replies after 2 PM

Recommendation: Add staff coverage from 1-3 PM or enable auto-qualification during lunch.
```

### Scene 5 — Close (1:15–1:30)

```
[Screen text:]
"Jawab finds the patients your clinic is already losing."
"72-hour setup. Weekly intelligence."
"Founding rate: AED 5,000 setup including first 30 days."

[CTA: "Reply AUDIT for a free leak check on your clinic."]
```

## What This Demo Must Show

1. A real, relatable scenario (missed call during lunch)
2. Automatic patient recovery (not manual, not chatbot)
3. Arabic + English capability
4. Clear staff handoff (not replacing staff)
5. Weekly intelligence report (the retention anchor)
6. Conservative money framing (at-risk value, not guaranteed revenue)
7. Clear CTA

## What This Demo Must NOT Show

- "ZERO HUMAN EFFORT" (sounds like replacing staff)
- Complex technical architecture
- Dashboard wireframes or admin panels
- Pricing comparison tables
- Generic AI / automation language
- Competitor bashing

## How To Build This Demo

### Option A — Loom Recording

- Record yourself walking through a mockup of the flow
- Use Google Sheets or a simple HTML page as the "staff dashboard"
- Show a real WhatsApp conversation (with test numbers)
- Show a real-looking report (use your Intelligence Report template)

### Option B — Video/Animation

- Use the existing jawab_demo.html as the cinematic version
- Build a separate practical walkthrough that looks like screen recordings

### Option C — Live Demo

- On a discovery call, share screen and walk through:
  1. "Here's what happens when a patient calls and no one picks up"
  2. "Here's what Jawab sends them"
  3. "Here's what your staff sees"
  4. "Here's what you see every week"
