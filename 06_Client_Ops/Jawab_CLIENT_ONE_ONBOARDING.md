# Jawab Client One Onboarding

This is the exact sequence when someone says yes.

## Immediately After Yes

Send within 1 hour:

1. **Invoice** — filled with their clinic name, amount, payment details
2. **Service agreement** — with their clinic name, selected package, effective date
3. **DPA** — data processing addendum
4. **Setup checklist** — what you need from them
5. **Welcome message**

### Welcome WhatsApp Message

```
Welcome to Jawab.

Over the next 72 hours I will:
1. Configure your recovery flow
2. Confirm your clinic details
3. Test the patient path
4. Prepare the first Jawab Intelligence Report

I will keep this thread simple: setup items, approvals, and recovered-patient updates.

First step: I need a few details from your team. Sending the checklist now.
```

## Setup Checklist — What You Need From Client

Send as a simple numbered list on WhatsApp or email:

```
Jawab Setup Checklist for [Clinic Name]

1. Clinic full name (as patients see it)
2. Clinic hours (weekdays + weekends + holidays)
3. Services list (especially high-ticket: implants, veneers, cosmetic, ortho)
4. High-ticket services to prioritize for recovery
5. Booking link or booking process (Cal.com / website form / phone / WhatsApp)
6. Escalation staff contact (name + WhatsApp of person who handles urgent inquiries)
7. Main WhatsApp number for patient communication
8. Google review link
9. Languages used with patients (Arabic only / English only / both)
10. Approved greeting text (what patients should see first)
11. Pricing/insurance boundaries (what NOT to discuss with patients)
12. Handoff rules (when does Jawab pass to staff vs continue qualifying?)
```

## First 72 Hours

### Day 0 — Collect and confirm

- Receive payment or proof of transfer
- Send invoice confirmation / receipt
- Collect setup checklist answers
- Confirm high-ticket services
- Confirm staff contact
- Confirm WhatsApp path

### Day 1 — Build

- Create clinic tracker in Google Sheets
- Draft recovery WhatsApp scripts (Arabic + English)
- Draft missed-call response flow
- Draft Instagram DM triage scripts
- Configure manual/semi-manual workflow
- Test staff handoff (send test message to staff contact)

### Day 2 — Test

- Run patient journey test:
  - Call clinic from unknown number
  - Send WhatsApp message asking about a service
  - Check Instagram DM response
  - Check website booking path
- Record Loom walkthrough for clinic owner
- Confirm report format and delivery day

### Day 3 — Go Live

- Activate recovery workflow (manual or semi-automated)
- Monitor incoming inquiries
- Log every interaction
- Send first proof screenshot to clinic owner

## First 7 Days

- Daily check-in with clinic staff contact
- Show every recovered opportunity
- First mini-report at end of week
- Record screenshots (anonymized) for proof archive
- Note any objections or edge cases

## Day 14

- Present first full Intelligence Report
- Show recovered conversations vs missed
- Present conservative at-risk patient value
- Ask: "Is this worth continuing?"
- If yes: confirm monthly renewal
- If concerns: identify and fix

## Day 30

- Full monthly Intelligence Report
- Renewal decision
- Recommend next module (Visible, Reviews, Treatment Plan Rescue)
- Ask for referral if value exists
- Ask for anonymized case study permission

## What Could Go Wrong

| Problem | Solution |
|---------|----------|
| Staff doesn't respond to handoffs | Set up direct WhatsApp thread with staff contact. Escalate to owner if ignored twice. |
| Clinic provides wrong/outdated info | Re-verify during Day 2 testing. Don't go live with unverified data. |
| No missed calls in first week | Proactive: check Google Ads, IG, website traffic. If clinic genuinely has low inbound, focus on post-consult follow-up and review capture instead. |
| Owner expects guaranteed revenue | Reframe in first call: "Jawab catches opportunities that would otherwise disappear. Results depend on your inbound demand and staff follow-through." |
| Payment delay | Don't start setup until payment clears or proof of transfer is received. No exceptions. |
| Client wants changes mid-setup | Accept reasonable changes. If scope expands, note it and address at Day 14 review. |
