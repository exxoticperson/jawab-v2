### 10 Script Frameworks

**Framework 1 — The Cold Audit**
```
HOOK: [Shocking finding from real action you took]
CONTEXT: "Last week I [called / visited / analyzed] [X clinics in Y city]"
FINDING: Walk through what you found specifically
IMPLICATION: "This means [expensive consequence for clinic owner]"
CTA: "If your clinic does this — comment AUDIT below"
```

**Framework 2 — The Insider Reveal**
```
HOOK: "Nobody talks about this inside dental clinics"
SETUP: "As a dental student I see this every single week"
REVEAL: One specific operational problem, described visually
REFRAME: "This isn't a people problem. It's a systems problem."
CTA: "Save this if you run or work in a clinic"
```

**Framework 3 — The Tool Breakdown**
```
HOOK: "This AI tool changed how I run [X] completely"
PROBLEM: What you were doing before and why it was broken
TOOL: What it is, what it does, why it works
RESULT: Specific outcome — time saved, money made, leads generated
CTA: "Comment TOOL and I'll send you the link"
```

**Framework 4 — The Build Update**
```
HOOK: "Here's what building Jawab actually looked like this week"
REALITY: Honest, specific — what broke, what worked, what surprised you
LESSON: One thing you'd do differently
INVITE: "Building something? DM me — let's compare notes"
```

**Framework 5 — The Hot Take**
```
HOOK: Counterintuitive or controversial one-liner
EXPAND: "Here's why I actually believe this"
EVIDENCE: 2–3 specific, real data points
FLIP: "The builders/clinics that get this right do [X] instead"
CTA: "Agree or disagree — comment below"
```

**Framework 6 — The Number**
```
HOOK: Specific number that creates immediate curiosity
BREAKDOWN: What that number actually represents in human terms
ROOT CAUSE: Why this is happening — the real reason
SOLUTION TEASE: "The fix is not [obvious wrong answer]"
CTA: "DM me RECOVER to see the full breakdown"
```

**Framework 7 — The POV**
```
"POV: You're a patient who just DMed a premium dental clinic in Dubai"
Play the experience from patient perspective in real time
Show every failure point as it happens
CLOSE: "This is why clinics with beautiful Instagram pages lose to clinics with fast replies"
```

**Framework 8 — The Before/After**
```
HOOK: "This clinic was losing AED [X] every single month"
BEFORE: Describe the broken state with specific details
SHIFT: "One operational change fixed it"
AFTER: The result — specific, credible, not inflated
CTA: "Comment AUDIT — I'll tell you if your clinic has the same leak"
```

**Framework 9 — The List**
```
HOOK: "X signs your clinic is bleeding revenue and doesn't know it"
LIST: Each point punchy, text on screen, fast delivery
CLOSER: "If 3 or more of these are true right now — this is urgent"
CTA: "Comment how many apply to you"
```

**Framework 10 — The Comparison**
```
HOOK: "Two clinics. Same location. Same services. Same prices."
SETUP: Build the scenario — make it feel real
REVEAL: The one thing different between them (communication system)
OUTCOME: Revenue or patient retention difference
CLOSE: "Which clinic is yours right now?"
```
