# Jawab V2

Jawab V2 is the clean operating repository for the current Jawab sprint.

Jawab is a WhatsApp-first dental patient recovery offer, sold with a voice/demo layer, deployed online-first, and optimized for fast outreach and first revenue.

## Start Here

Open these files in order:

1. `00_START_HERE/CURRENT_START_HERE.md`
2. `01_Strategy/Jawab_EXECUTION_DASHBOARD.html`
3. `01_Strategy/00_JAWAB_LOCKED_PLAN.md`
4. `01_Strategy/Jawab_CONTROL_TOWER.md`
5. `02_Outreach_and_Data/01_READY_TO_SEND_TOP30_WORKING.csv`
6. `02_Outreach_and_Data/Jawab_Morning_Send_Pack.md`

## Repository Structure

- `00_START_HERE`
  - entrypoint files and reading order
- `01_Strategy`
  - live operating plan, dashboard, control tower, execution playbook
- `02_Outreach_and_Data`
  - outreach packs, lead sheets, ICP notes, market and competitor notes
- `03_Demo_and_Assets`
  - live HTML demo and demo-support assets
- `04_System_and_Skills`
  - agent model, make blueprint, skill-writer system, and project-local skills
- `05_Backend_Reference`
  - backend logic saved as reference only, not production
- `99_Archive`
  - historical context and older materials kept for reference only

## Current Rules

- ship before tweak
- send before system-building
- WhatsApp first when a direct path exists
- collect replies before adding more tooling
- do not treat archive files as source of truth

## Current Tool Direction

- now: `WhatsApp Business`, `Google Workspace`, `Loom`
- soon: `Twilio`, `Make`, `Apify`, `Vercel`
- later: `Airtable/HubSpot`, `Clay`
- not now: local `n8n`, custom backend rebuilds, voice routing experiments
