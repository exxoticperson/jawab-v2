# Jawab V2

Jawab V2 is the clean operating repository for the current Jawab sprint.

Jawab is a `Clinic Revenue Leak Audit + Patient Recovery System` for premium dental clinics. The first paid offer is `Jawab Audit + Jawab Recover`, not a generic chatbot, AI receptionist, or broad automation agency.

- `Jawab Audit`: free clinic leak audit.
