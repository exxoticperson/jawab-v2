# Skill: Gulf Dialect Copy

## Goal

Write Arabic/English Jawab copy that feels human, short, and commercially credible for UAE dental clinics.

## Use When

- drafting WhatsApp messages
- writing bot first messages
- preparing voice-note scripts
- localizing demo copy

## Rules

- keep the message short enough to read on a phone
- use Arabic only when it increases trust
- avoid stiff MSA unless the clinic is formal
- do not overdo dialect slang
- do not pretend to know a precise local phrase if uncertain
- preserve the Jawab positioning: patient recovery, not generic AI

## Default Message Shape

1. direct name or clinic reference
2. one concrete pain proof
3. Jawab recovery hook
4. 60-second demo CTA

## Output

- Arabic-first version
- English version
- voice-note version if requested
