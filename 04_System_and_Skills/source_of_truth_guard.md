# Skill: Source Of Truth Guard

## Goal

Prevent old Jawab ideas, pricing, tools, or positioning from leaking back into current execution.

## Use When

- reading old Jawab files
- answering "where are we?"
- updating dashboard, README, strategy, or pitch docs
- comparing another model's output against Jawab

## Current Truth Check

Before making a decision, check these files first:

- `00_START_HERE/CURRENT_START_HERE.md`
- `00_START_HERE/READ_IN_THIS_ORDER.md`
- `01_Strategy/Jawab_EXECUTION_DASHBOARD.html`
- `01_Strategy/Jawab_CONTROL_TOWER.md`
- `01_Strategy/00_JAWAB_LOCKED_PLAN.md`

## Reject If It Says

- voice-first deployment as the initial product
- local backend or local tunnel as production
- local n8n as the default sprint stack
- pricing below the current floor unless explicitly approved
- "AI receptionist" as the main opener
- old pilot pricing as current pricing

## Output

- current truth used
- stale item rejected, if any
- decision or corrected wording
