# Skill: Dashboard Art Direction

## Goal

Keep Jawab's operator surfaces sharp, minimal, and usable without drifting into generic AI-dashboard styling.

## Use When

- editing `Jawab_EXECUTION_DASHBOARD.html`
- redesigning internal control surfaces
- making visual asset choices for the operator view

## Visual Rules

- Treat the dashboard like a working console, not a marketing page.
- Put the actual work in the first viewport: tasks, score, queue, and blockers.
- Use one accent color family only.
- Avoid decorative hero copy, generic "premium" subtitles, and glossy card grids.
- Prefer sections, rails, dividers, and clusters over stacked cards.
- Keep language operational: status, next action, send order, objections, proof.
- Motion should help scan order or state change, not create atmosphere for its own sake.
- Typography should feel deliberate and modern, but the data should still win over the styling.

## Reject If It Looks Like

- a SaaS landing page
- a purple gradient dashboard
- a gold-and-black luxury template
- a page that explains itself more than it helps operate
- a UI where every block is equally loud

## Desired Feel

- precise
- slightly severe
- premium through restraint
- fast to scan
- worth opening every day
