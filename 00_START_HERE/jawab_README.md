# Jawab One-Page System Overview

Jawab is a `Clinic Revenue Leak Audit + Patient Recovery System` for premium dental clinics.

The first sale is not an AI receptionist, chatbot, or broad automation service. The first sale is:

`We find and fix patient revenue leaks: missed calls, slow WhatsApp replies, post-consult drop-offs, weak review capture, and broken booking paths.`

## Current Offer

- `Jawab Audit`: free clinic leak audit.
- `Jawab Recover`: AED `5,000` setup including first 30 days, then AED `1,500/month`.
- founding floor: AED `3,500` upfront only when needed.

1. Find a clinic leak.
2. Send a specific WhatsApp/IG/Gmail message.
3. Share the demo or Loom audit.
4. Run discovery call.
5. Close Jawab Recover.
6. Capture proof.
7. Upsell only after value is visible.
